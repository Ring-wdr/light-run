# 라이트런 개인정보처리방침

시행일: 2026년 11월 1일

라이트런(이하 "앱")은 회원 가입·로그인·광고가 없는 러닝 기록 앱입니다. 앱 개발자(이하 "개발자")는 이용자의 기록을 서버로 가져가지 않습니다.

## 1. 앱이 다루는 정보

| 정보 | 쓰는 곳 | 저장 위치 |
|---|---|---|
| 위치(정확한 위치) | 달리기·걷기를 기록하는 동안 거리, 페이스, 경로를 계산 | 이용자 기기 안(앱 데이터베이스) |
| 기록·코스·설정 | 기록 목록, 상세, 다시 보기, 내 코스 | 이용자 기기 안 |

- 위치는 이용자가 **시작**을 누른 뒤부터 **종료**를 누를 때까지만 사용합니다. 기록 중에는 화면이 꺼지거나 다른 앱을 쓰는 동안에도
  기록이 끊기지 않도록 알림이 표시된 상태로 위치를 받습니다. 기록 중이 아닐 때는 위치를 사용하지 않습니다.
- 앱은 기록을 개발자나 다른 서버로 보내지 않습니다. 개발자는 이용자의 기록을 볼 수 없습니다.

## 2. 외부 지도 서비스

지도를 보여 주기 위해 아래 서비스의 SDK를 씁니다. 지도를 여는 화면에서만 지도 이미지를 내려받으며, 이때 각 서비스가
기기 정보(OS 버전·모델), IP 주소, SDK 식별자, 오류 정보 등을 수집할 수 있습니다. 앱은 이용자의 기록(경로·위치 기록)을 이 서비스에 보내지 않습니다.

- Google Maps SDK for Android(기록 상세 지도): [Google 개인정보처리방침](https://policies.google.com/privacy)
- Mapbox Maps SDK(3D 다시 보기): [Mapbox 개인정보처리방침](https://www.mapbox.com/legal/privacy). 앱에서 Mapbox 텔레메트리 전송은 꺼 두었습니다.

## 3. 이용자가 직접 보내는 경우

- **공유하기**: 이용자가 공유를 누르면 기록 카드 이미지(경로 모양, 거리, 시간, 페이스)를 이용자가 고른 앱(카카오톡 등)으로 보냅니다.
- **백업(GPX)**: 이용자가 백업을 누르면 기록 파일을 만들어 이용자가 고른 곳에 저장하거나 보냅니다. 파일에는 기록한 위치가 들어 있습니다.

이렇게 보낸 정보는 받는 앱·서비스의 정책을 따릅니다.

## 4. 보관과 삭제

- 기록은 이용자가 지우기 전까지 기기 안에 남습니다. 앱에서 기록을 하나씩 지울 수 있고, 앱을 삭제하면 모든 기록이 함께 지워집니다.
- 개발자는 이용자 기록을 갖고 있지 않으므로 따로 삭제를 요청할 정보가 없습니다.

## 5. 권한

| 권한 | 이유 |
|---|---|
| 위치(앱 사용 중) | 기록 중 거리·경로 계산 |
| 포그라운드 서비스(위치) | 화면이 꺼져도 기록이 이어지도록 기록 중 알림 표시 |
| 알림(Android 13 이상) | 기록 중임을 알리는 알림 표시. 허용하지 않아도 기록은 됩니다 |
| 인터넷 | 지도 이미지 내려받기 |
| 진동, 화면 켜짐 유지(WAKE_LOCK) | 기록 중 음성 시간 안내를 예약한 시각에 재생 |

## 6. 아동

앱은 만 13세 미만 아동을 대상으로 하지 않습니다.
